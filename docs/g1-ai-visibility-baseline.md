# Andrelook G1 AI visibility baseline

Benchmark date: 2026-10-09  
Baseline surface available in this run: ChatGPT web search  
Result: Andrelook mentioned in **0/32** prompts and linked in **0/32** prompts before G1 release.

## Method

The fixed query set uses ordinary customer wording across ET, RU and EN. Each query was run once against the available ChatGPT web-search surface. “Mentioned” means Andrelook appeared in the returned answer/result set; “linked” means an `andrelook.store` URL was returned. Approximate prominence is recorded as “absent” when neither occurred. Representative returned sources are recorded to make the baseline reproducible without treating the result set as an endorsement.

Google/Gemini and Bing/Copilot AI-answer surfaces were not independently benchmarked because an authenticated measurement surface was not available in this run. Search Console is pending DNS verification, and Bing Webmaster is pending an owner-selected sign-in identity. These are external follow-ups, not technical blockers.

## Entity and organic baseline

- A `site:andrelook.store` web-search sample returned no Andrelook domain result.
- A quoted `"Andrelook" Tallinn` sample was dominated by an unrelated eBay seller using the same string.
- Search Console performance/indexation counts were unavailable because the new Domain property still requires authoritative Zone DNS verification.
- Bing crawl/indexation counts were unavailable because Bing Webmaster requires an owner-selected account identity.
- This baseline is therefore a true pre-discovery state: no visibility claim, no ranking estimate and no forecast.

## Recheck protocol

Keep this prompt set unchanged for comparison. Re-run after Search Console/Bing verification and after search engines have had reasonable crawl time. Record the platform, date, mention/link status, cited Andrelook URL and competitors. Do not alter content simply to force an AI mention; improve only facts, crawlability and customer usefulness.
